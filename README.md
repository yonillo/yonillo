### 🚀 Featured Engineering Projects

**📡 [Real-Time Satellite Monitoring (dacd-data-app)](https://github.com/OmeletCode/dacd-data-app)**  
*Live Starlink telemetry ingestion & predictive rain fade analysis.*  
- **Stack:** Java, ActiveMQ, Grafana, Docker.  
- **Highlights:** Lambda Architecture, distributed event streaming, and real-time telemetry processing.

**⛽ [Gran Canaria Fuel Data Pipeline (ETL)](https://github.com/yonillo/gc-data-hub-pipeline)**  
*Automated daily ETL pipeline persisting regional fuel metrics into columnar storage.*  
- **Stack:** Python, Pandas, Apache Parquet, GitHub Actions, Docker.  
- **Highlights:** 80% storage footprint reduction via Parquet, serverless cron orchestration, and automated schema validation.

**🏄 [Surf Decision Gran Canaria (DSS)](https://github.com/yonillo/Surf-Dashboard-gc)**  
*Real-time oceanographic decision-support platform for coastal surf spots.*  
- **Stack:** Python, Streamlit, Plotly, PyDeck, Open-Meteo APIs.  
- **Highlights:** Heuristic multi-variable decision engine, 24h golden-window forecasts, live webcam ground-truth feeds.  
- **Live Demo:** [surf-dashboard-gc.streamlit.app](https://surf-dashboard-gc.streamlit.app/)

**📊 [European Youth Employment Dynamics & ARIMA Forecasting](https://github.com/youth-employment-analysis-europe)**  
*Econometric analysis and demographic time-series forecasting across EU states.*  
- **Stack:** R, Shiny, flexdashboard, Tidyverse, fpp3 (ARIMA), Leaflet.  
- **Highlights:** Macroeconomic ARIMA projections, interactive choropleth GIS cartography, and reactive demographic filters.

**🛰️ [Satellite Image Semantic Segmentation (U-Net)](https://github.com/yonillo/satellite-segmentation-botija)**  
*Deep learning computer vision for wind farm terrain viability in Botija, Gran Canaria.*  
- **Stack:** MATLAB, U-Net, Adam Optimizer, Computer Vision Toolbox.  
- **Highlights:** Pixel-level ground-truth semantic mask training, automated orthophoto patch extraction, and topographic class segmentation.
